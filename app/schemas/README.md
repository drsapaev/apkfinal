# Room Database Schema Exports

## Current state

The `app/schemas/com.aistudio.clinicsystem.data.db.ClinicDatabase/` directory
contains Room's JSON schema exports. These are used by `MigrationTestHelper`
to verify that migrations produce the correct final schema.

**Currently committed:** `4.json` (initial schema, version 4)

**Missing (Medium-4 audit finding):** `5.json`, `6.json`, `7.json`, `8.json`,
`9.json` — schema exports for versions 5 through 9.

## How to generate the missing schema files

The schema files are auto-generated by Room's KSP annotation processor when
`exportSchema = true` (set in `ClinicDatabase.kt`). To generate them:

```bash
cd /path/to/apkfinal
./gradlew :app:kspDebugKotlin
```

This runs KSP, which processes the `@Database` annotation and writes JSON
schema files to `app/schemas/com.aistudio.clinicsystem.data.db.ClinicDatabase/`.

After generation, commit ALL schema files (5.json through 9.json) to the
repository. They are required for:

1. `MigrationTestHelper`-based tests in `androidTest` (instrumented tests)
2. Verifying that migrations produce the correct final schema
3. Debugging schema drift between entity definitions and database state

## Why only 4.json is committed

The project was initially at version 4 when `exportSchema = true` was first
enabled. Versions 5-9 were added via migrations (MIGRATION_4_5 through
MIGRATION_8_9) but the schema files were not committed at each step. This
is a gap in the CI process — schema files should be committed whenever a
migration is added.

## Migration test coverage

`MigrationTest.kt` (unit test, Robolectric) covers:
- All 5 migrations are registered in `Migrations.ALL`
- Data persistence across close/reopen with migrations registered
- New columns added by MIGRATION_6_7 (etag, version, lastHttpCode, updatedAt)
- New tables created by MIGRATION_7_8 (doctors) and MIGRATION_8_9 (lab_results)

Full `MigrationTestHelper`-based tests (which require the committed schema
JSON files) are deferred to `androidTest` (instrumented tests) — see
Stage 10 test fund roadmap.
